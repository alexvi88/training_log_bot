# Живая проверка английской локализации

Что проверять руками после деплоя. Юнит-тесты мокают Bot API: они говорят, что
бот **отправил** правильный вызов, и никогда — что клиент правильно **нарисовал**
результат. Всё в этом файле — про второе.

Нужны два аккаунта: **чистый** (никогда не писал боту) и **старый**. Половина
пунктов проверяется только на новом, половина — только на старом.

---

## 0. Перед началом

- [ ] Ветка задеплоена, бот перезапущен.
- [ ] В логах после старта нет `i18n: ключ ... не найден`. Одна такая строка =
      экран покажет технический ключ вместо текста. **Это блокер.**
- [ ] На телефоне язык интерфейса Telegram — русский (нужно для пункта 6).

---

## 1. Старый пользователь не должен ничего заметить

Главный риск всей работы: локализация трогала каждый экран.

- [ ] `/start` — меню на русском, ничего не съехало.
- [ ] Записать подход: `100 8` → записалось, карточка на русском.
- [ ] Прогресс, История, Достижения, Программы — открываются, текст русский.
- [ ] Язык **остался русским сам**, никто не спрашивал и не переключал.
- [ ] Названия упражнений и программ в аккаунте не изменились.

Если что-то из этого сломалось — откатывать, не разбираясь.

---

## 2. Новичок: выбор языка

Нужен аккаунт, который боту никогда не писал.

- [ ] `/start` → **первым** приходит экран `🌐 Русский / English`.
- [ ] Догадка помечена точками (`• English •`) по языку телефона.
- [ ] Под полем ввода уже есть кнопки — и **нет** сообщения «⌨️ Обновил меню».
- [ ] Нажать `English` → приветствие `HEY ATHLETE!`, кнопки внизу стали
      `Workout / Menu / AI Coach`.
- [ ] `/start` ещё раз → экран выбора **не** повторяется.

---

## 3. Основной цикл на английском

- [ ] Начать тренировку, выбрать группу мышц — **названия групп английские**
      (`CHEST`, `LEGS`), не `ГРУДЬ`.
- [ ] Выбрать упражнение из каталога — название английское.
- [ ] **Поиск: набрать `bench`** → находит `Barbell Bench Press`. Это чинилось
      дважды, проверить обязательно.
- [ ] Записать `100 8` → карточка на английском, слово `set`, не `подход`.
- [ ] Завершить тренировку → сводка и **картинка**: в ней `WORKOUT`, `TARGET`,
      `/wk` — ни одной кириллической буквы.
- [ ] Апострофы выглядят как `'`, а не как `&#x27;`.

---

## 4. Данные, которые остаются навсегда

Самое неприятное: тут ошибка не видна сразу, а расходится история.

- [ ] Добавить упражнение из каталога на английском.
- [ ] Переключиться на русский (Настройки → Язык), добавить **то же самое**
      упражнение из каталога.
- [ ] Открыть Упражнения → должно быть **ОДНО**, не два. Если два — история и
      рекорды разъехались, **блокер**.
- [ ] Взять готовую программу на английском → дни и состав английские.
- [ ] Удалить эту программу → упражнения, добавленные руками, **не исчезли**.

---

## 5. AI-тренер

- [ ] Спросить по-английски `am I getting stronger?` → ответ **по-английски**.
- [ ] В ответе появились кнопки действий → их подписи английские
      (`Delete:`, `Merge:`, `Share:`).
- [ ] Попросить собрать программу → экран прогресса `Building your program`,
      вопросы на английском.
- [ ] Превью программы и то, что сохранилось, называются **одинаково**.
- [ ] Голосом сказать `two twenty five for five` → распозналось как 225×5.
      Раньше молча не работало.

---

## 6. Что Telegram рисует сам

Не в чате, а вокруг него.

- [ ] Набрать `/` → меню команд. **На русском телефоне оно останется русским —
      это ожидаемо** (Telegram выбирает по языку клиента, не по нашей
      настройке). Проверить, что оно вообще есть и не пустое.
- [ ] На устройстве с английским языком системы — меню команд английское.
- [ ] Карточка бота в поиске: `HEY ATHLETE! READY TO TRAIN?`

---

## 7. Пуши

Быстро не проверить — приходят по расписанию. Заказать через админку, если есть.

- [ ] Пуш англоязычному — на английском, начинается с `HEY ATHLETE!`.
- [ ] Кнопка под пушем на английском и продолжает мысль текста.
- [ ] Пуш русскому в тот же день — на русском. Проверять надо **обоих**: язык
      ставится на каждого в цикле, и ошибка здесь выглядит как «все получили
      язык первого».

---

## 8. Мини-игра и внешние страницы

- [ ] `/game` на английском → игра английская, включая `<title>` вкладки.
- [ ] **Переключить язык на English, оставив телефон русским** → игра всё равно
      английская. Это чинилось отдельно: страница знает только язык телефона,
      наш выбор ей передаётся ссылкой.
- [ ] Сообщение тренера после забега — на языке пользователя.
- [ ] `/mcp` → экран на английском.
- [ ] Открыть страницу подключения в браузере с английской локалью → страница
      английская.

---

## Если что-то нашлось

Записать: **какой язык был выбран**, **язык телефона**, **экран**, скриншот.
Первые два обязательны — почти все найденные ошибки были именно про
расхождение этих двух вещей.
