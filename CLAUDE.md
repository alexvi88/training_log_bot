# training_log_bot

Telegram-бот — дневник тренировок с AI-тренером (aiogram, SQLite, деплой на Amvera).

## Тон голоса — обязательно к любому тексту

Любой текст, который видит пользователь — экраны, кнопки, ошибки, пуши, промпты AI,
тексты мини-игр, — пишется по гайду **`TONE_OF_VOICE.md`**. Перед тем как писать или
менять пользовательские тексты, прочитай его целиком. Ключевые правила:

- Один персонаж на весь продукт — тренер из подвальной качалки: говорит от первого
  лица («Записал», «пересчитал сам»), к пользователю строго на «ты». Страдательный
  залог запрещён.
- Брендовая формула «ПРИВЕТ АТЛЕТ, » — капсом, запятая после АТЛЕТ, без запятой
  внутри. Никогда: «боец», «пользователь», «друг», «ПРИВЕТ, АТЛЕТ».
- Капс — приём заголовков и пушей, не основного текста. Регистры внутри одного
  сообщения не смешивать.
- Подколки — только про пропуски тренировок. Рекорды, возвращения, новички,
  ошибки ввода, малый вес — только поддержка.
- Ошибка отвечает на два вопроса: что случилось и что сделать дальше, голосом
  тренера («Не понял вес. Напиши число, например 80»).
- Любое утверждение о данных пользователя отправляется только когда данные его
  подтверждают.

## Откуда приходят люди

Источник каждого нового атлета пишется на первом `/start` из метки deep link'а
(`acquisition.py`, `db.set_user_source`) — один раз, первое касание побеждает.
Воронка по источникам — админская команда `/growth`. Ссылки под каналы,
тексты для каталогов ботов и черновик статьи — в **`GROWTH.md`**.

## Проверки перед пушем

- Тесты: `python -m pytest -q` — весь набор должен быть зелёным.
- Линт: `ruff check .`.
