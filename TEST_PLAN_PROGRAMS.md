# План ручного прогона: программы тренировок

Составлен по коду (`handlers/routines.py`, `handlers/workout.py`,
`handlers/sharing.py`, `handlers/ai_trainer.py`, `keyboards.py`, `db.py`) и по
тому, что уже покрыто в `tests/`. Ниже — то, что автотестами **не** покрыто,
то есть самое ценное для ручного прогона. Отметки: `[x]` пройдено,
находки — в `BUGS_LIVE_TESTING.md`.

Константы для сверки арифметики: `MAX_ROUTINES_PER_USER = 30`,
`MAX_PROGRAM_NAME_LENGTH = 48`, `MAX_SHARED_DAYS = 6`,
`MAX_SHARED_EXERCISES = 30`, `ROUTINE_SOURCE_PAGE_SIZE = 6`,
`RECENT_EXERCISES_LIMIT = 8`, `_PLAN_LABEL_MAX = 44`,
`RECENT_PROGRAM_DAYS = 30`, `MAX_RECENT_PROGRAM_BUTTONS = 3`.

## Где вероятнее всего найдётся новое

1. Старт дня программы поверх **непустой** активной тренировки — ветка без автотестов.
2. Экран программы строится без бюджета символов — большая многодневка может не влезть в лимит Telegram 4096.
3. Правка/удаление программы посреди тренировки по ней и восстановление плана.
4. Архивация и слияние упражнений, используемых в программах.
5. AI: конфликт имён, устаревший черновик, «Начать по ней», правка сохранённой программы.
6. Приём чужой визитки вторым аккаунтом.
7. Вынос и удаление последнего дня — что происходит с осиротевшей программой.

## 1. Старт и стык с активной тренировкой

- [x] Пустая активная тренировка + старт дня программы → молча продолжает в ней (см. находку 15d).
- [x] Непустая активная тренировка + старт дня → ожидается «У тебя не закрыта тренировка от <дата>» с `Завершить и начать` / `Вернуться к ней`. Проверить обе ветки и случай, когда активной тренировки уже нет.
- [x] Пустой день программы → обычный пикер (находка 4c2).
- [ ] День с архивированным упражнением: оно не должно попасть в план и в счётчик «осталось».

## 2. Очередь дней

- [x] Никогда не тренированная программа → «Сегодня: первый день».
- [x] Прошёл день → очередь сдвинулась, день помечен «сегодня», счётчик «N тренировок по ней».
- [x] Переставил порядок дней → очередь пересчиталась верно.
- [x] Тренировка по дню вне очереди → работает: старт Дня C напрямую (не по
  очереди) открыл его план корректно, счётчик и «Дальше по кругу» посчитались
  от фактически пройденных дней, а не от порядка выбора.
- [ ] Начал день и бросил, не завершив → день остаётся «ещё не делал».
- [x] Последний день → очередь заворачивается на первый: подтверждено кодом
  `next_program_day` (db.py:4517) — «день после последнего трениро­ванного, с
  переносом на первый»; вживую очередь после каждого пройденного дня
  двигалась к следующему без пропусков (B→A→C→D→B по кругу).

## 3. «Осталось по программе»

- [x] Кнопка `Программа · осталось N`, список остатка, выбор не по порядку.
- [x] Сверить N руками: уменьшается на 1 за блок, не считает сделанное —
  подтверждено (5→4→3 и т.д., неплановые упражнения счётчик не трогают).
- [ ] Обрезка подписи на 44 символах: длинное имя + схема.
- [x] `Убрать из плана`, в том числе убрать последнее → «Программа пройдена» —
  работает **только** через этот путь; при обычном линейном прохождении
  экран практически недостижим (находка 20).
- [x] Экран «Программа пройдена»: сверить N упражнений, M подходов, тоннаж —
  сошлось (1 упражнение, 2 подхода, 1.6 тонны = 100×8+100×8).
- [x] Тап по кнопке из устаревшего экрана → по коду `live_plan_pick`
  (handlers/workout.py:2592-2598) отдаёт alert «Это упражнение уже не в
  плане» при индексе за пределами списка — без падения; живьём стабильно не
  воспроизвести (бот перерисовывает сообщение в одном id), поведение
  подтверждено чтением кода и веткой `live_plan_skip` с тем же алертом.

## 4. Прогрессия и цели

- [x] `План: N×A–B`, `В прошлый раз`, `Цель`, `Цель выполнена`.
- [x] Двойная прогрессия: взял верх диапазона → +шаг (см. находку 4 про расхождение с обещанным «с низа»).
- [x] Упражнение своим весом в программе → цель в повторах, без веса —
  подтверждено («Цель: 13 повторов», без «×кг»).
- [ ] Переключить кг↔фунты → шаг из правила пересчитан, `План` не изменился.
- [x] Ручная схема убивает правило прогрессии, бот предупреждает.

## 5. Отклонение от плана

- [x] Открыть плановое упражнение вручную через `Упражнение` → уходит из
  очереди — подтверждено вживую.
- [x] Открыть внеплановое → счётчик не меняется — подтверждено вживую (3→3).
- [x] Суперсет: снятие одной половины не должно снимать вторую — на практике
  верно, но не благодаря защите от «снятия»: живой «Суперсет» никогда не
  создаёт настоящий связанный блок (см. находку 21), так что упражнения и не
  были связаны, снимать «вторую половину» физически нечего.
- [x] Уйти и вернуться → план тот же; но правка программы на него не влияет (находка 5).
- [ ] Открыть чужую визитку посреди тренировки → план восстанавливается минус сделанное.
