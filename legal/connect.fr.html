Connecter Journal d’athlète à Claude et ChatGPT

Journal d’athlète est une app pour iPhone et un bot Telegram pour noter tes séances. Le connecteur permet à une app d’IA que tu utilises de lire ton propre journal et de répondre à des questions sur ton entraînement.

Connecte-le une fois — et pose tes questions sur ton entraînement directement là-bas : « Est-ce que mon développé couché a progressé ces 3 derniers mois ? », « Quels muscles est-ce que je travaille trop peu ? », « Construis-moi un programme sur 4 jours à partir de ce que je fais déjà ».

Ce qu’il te faut

  • Un compte Journal d’athlète — l’app iPhone (Se connecter avec Apple) ou le bot Telegram @lightweight_log_bot. Les deux sont gratuits.
  • Claude (claude.ai, l’app de bureau ou mobile, Claude Code) ou ChatGPT.

Adresse du connecteur

https://athletediary.app/mcp

La connexion se fait par OAuth : il n’y a pas de mot de passe. Sur la page de confirmation, tu saisis un code à usage unique de 6 chiffres que toi seul peux obtenir :

  • dans l’app : Profil → « Connecter à Claude et ChatGPT » → « Obtenir le code » ;
  • dans le bot : envoie /mcp et choisis ton app — le code est dans le même message.

Le code dure 10 minutes et ne fonctionne qu’une fois. Un nouveau code annule le précédent.

Claude

  1. Paramètres → Connecteurs → Ajouter un connecteur personnalisé (ou trouve Journal d’athlète dans l’annuaire des connecteurs).
  2. Colle https://athletediary.app/mcp et touche Connecter.
  3. Sur la page de confirmation de Journal d’athlète, saisis le code et touche « Autoriser ».
  4. Vérifie : dans une nouvelle conversation, demande « montre mes dernières séances ».

Claude Code : claude mcp add --transport http athlete-diary https://athletediary.app/mcp, puis /mcp → Authenticate.

ChatGPT

  1. Trouve Journal d’athlète dans l’annuaire des apps de ChatGPT et touche Connecter. Tant que la fiche n’est pas en ligne : Paramètres → Apps & Connecteurs → Avancé → active le mode développeur, puis Créer, colle https://athletediary.app/mcp, Authentification — OAuth.
  2. Sur la page de confirmation de Journal d’athlète, saisis le code et touche « Autoriser ».
  3. Vérifie : active le connecteur dans une conversation et demande « montre mes dernières séances ».

Ce que le connecteur peut faire

Lecture — il ne modifie jamais rien :

  • get_training_overview — unités, statistiques, profil d’entraînement et liste de tes exercices.
  • get_active_workout — la séance en cours, s’il y en a une.
  • list_recent_workouts — les 1 à 10 dernières séances avec chaque série.
  • get_full_workout_history — jusqu’aux 200 dernières séances, pour les questions sur le long terme.
  • get_exercise_progress — un exercice : séries par date, charges de travail, e1RM, records.
  • compare_periods — les N derniers jours comparés aux N précédents, sur tous les exercices.
  • get_weekly_volume_by_group — séries de travail par groupe musculaire, cette semaine et la précédente.
  • get_muscle_recovery — le niveau de récupération de chaque groupe musculaire.
  • get_bodyweight_history — les pesées.
  • get_saved_programs — tes programmes, en liste ou l’un d’eux en entier.
  • get_program_adherence — à quel point tes séances suivent le programme enregistré.
  • list_exercise_catalog — le catalogue d’exercices intégré, par groupe musculaire.

Écriture — uniquement quand tu le demandes à l’app d’IA :

  • log_bodyweight — noter le poids de corps du jour.
  • delete_bodyweight_log — supprimer une pesée (l’app d’IA te demande de confirmer).
  • create_exercise — ajouter un exercice personnalisé.
  • copy_program — dupliquer un programme enregistré.

Le connecteur ne peut pas lire ta conversation avec le coach IA, renommer ni supprimer des séances, des exercices ou des programmes, ni voir ton e-mail, ton identifiant Apple ou ton compte Telegram. Jusqu’à 60 requêtes par minute.

Confidentialité et déconnexion

Tes données ne vont à l’app d’IA que lorsqu’elle appelle le connecteur à ta demande, et uniquement vers le compte que tu as confirmé avec le code. À partir de là, c’est la politique de confidentialité de cette entreprise qui s’applique. Pour déconnecter : dans l’app, Profil → « Connecter à Claude et ChatGPT » → « Apps connectées » ; dans le bot, /mcp → « Apps connectées » — ou supprime le connecteur dans l’app d’IA. Détails — dans la Politique de confidentialité.

Aide

  • Dans l’app : Profil → « Assistance & avis ».
  • Dans le bot : la commande /feedback.
