# Журнал площадок — где мы есть

Что и когда подали, куда выложились, чем кончилось. Только факты: дата,
ссылка, метка, статус. Планы и тексты для подачи — в `GROWTH.md`
(разделы 2, 3¾, Product Hunt), требования каталогов коннекторов — в
`docs/MCP_LISTING.md`.

Правило ведения: подал, опубликовался, получил ответ — строка сразу сюда тем же
днём, с датой. Статус меняешь — старый не стираешь, дописываешь в «Заметки».
Неизвестное пишется как `?`, а не догадкой.

Статусы: `черновик` → `запланировано` / `подано` → `на ревью` → `опубликовано` / `отказ` /
`не подаём`.
