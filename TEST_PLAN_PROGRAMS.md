# План ручного прогона: программы тренировок

Составлен по коду (`handlers/routines.py`, `handlers/workout.py`,
`handlers/sharing.py`, `handlers/ai_trainer.py`, `keyboards.py`, `db.py`) и по
тому, что уже покрыто в `tests/`. Ниже — то, что автотестами **не** покрыто,
то есть самое ценное для ручного прогона. Отметки: `[x]` пройдено,
находки — в `BUGS_LIVE_TESTING.md`.

Константы для сверки арифметики: `MAX_ROUTINES_PER_USER = 30`,
`MAX_PROGRAM_NAME_LENGTH = 48`, `MAX_SHARED_DAYS = 6`,
`MAX_SHARED_EXERCISES = 30`, `ROUTINE_SOURCE_PAGE_SIZE = 6`,
`RECENT_EXERCISES_LIMIT = 8`, `_PLAN_LABEL_MAX = 44`,
`RECENT_PROGRAM_DAYS = 30`, `MAX_RECENT_PROGRAM_BUTTONS = 3`.

## Где вероятнее всего найдётся новое

1. Старт дня программы поверх **непустой** активной тренировки — ветка без автотестов.
2. Экран программы строится без бюджета символов — большая многодневка может не влезть в лимит Telegram 4096.
3. Правка/удаление программы посреди тренировки по ней и восстановление плана.
4. Архивация и слияние упражнений, используемых в программах.
5. AI: конфликт имён, устаревший черновик, «Начать по ней», правка сохранённой программы.
6. Приём чужой визитки вторым аккаунтом.
7. Вынос и удаление последнего дня — что происходит с осиротевшей программой.

## 1. Старт и стык с активной тренировкой

- [x] Пустая активная тренировка + старт дня программы → молча продолжает в ней (см. находку 15d).
- [x] Непустая активная тренировка + старт дня → ожидается «У тебя не закрыта тренировка от <дата>» с `Завершить и начать` / `Вернуться к ней`. Проверить обе ветки и случай, когда активной тренировки уже нет.
- [x] Пустой день программы → обычный пикер (находка 4c2).
- [ ] День с архивированным упражнением: оно не должно попасть в план и в счётчик «осталось».

## 2. Очередь дней

- [x] Никогда не тренированная программа → «Сегодня: первый день».
- [x] Прошёл день → очередь сдвинулась, день помечен «сегодня», счётчик «N тренировок по ней».
- [x] Переставил порядок дней → очередь пересчиталась верно.
- [ ] Тренировка по дню вне очереди → подсказка идёт от него.
- [ ] Начал день и бросил, не завершив → день остаётся «ещё не делал».
- [ ] Последний день → очередь заворачивается на первый.

## 3. «Осталось по программе»

- [x] Кнопка `Программа · осталось N`, список остатка, выбор не по порядку.
- [ ] Сверить N руками: уменьшается на 1 за блок, не считает сделанное.
- [ ] Обрезка подписи на 44 символах: длинное имя + схема.
- [ ] `Убрать из плана`, в том числе убрать последнее → «Программа пройдена».
- [ ] Экран «Программа пройдена»: сверить N упражнений, M подходов, тоннаж.
- [ ] Тап по кнопке из устаревшего экрана → «Это упражнение уже не в плане», без падения.

## 4. Прогрессия и цели

- [x] `План: N×A–B`, `В прошлый раз`, `Цель`, `Цель выполнена`.
- [x] Двойная прогрессия: взял верх диапазона → +шаг (см. находку 4 про расхождение с обещанным «с низа»).
- [ ] Упражнение своим весом в программе → цель в повторах, без веса.
- [ ] Переключить кг↔фунты → шаг из правила пересчитан, `План` не изменился.
- [x] Ручная схема убивает правило прогрессии, бот предупреждает.

## 5. Отклонение от плана

- [ ] Открыть плановое упражнение вручную через `Упражнение` → уходит из очереди.
- [ ] Открыть внеплановое → счётчик не меняется.
- [ ] Суперсет: снятие одной половины не должно снимать вторую.
- [ ] Уйти в Историю / Прогресс / Еду / Упражнения / AI и вернуться → план тот же, убранное не воскресает.
- [ ] Открыть чужую визитку посреди тренировки → план восстанавливается минус сделанное.

## 6. Длинные тексты и лимиты

- [ ] Программа 10 дней × 12 упражнений → влезает ли экран программы в 4096 символов.
- [ ] Имя программы ровно 48 символов, имя дня 48 + упражнение 60+ → вёрстка списка, заголовков, кнопок.
- [ ] Схема подходов 100+ символов и с HTML (`<b>3x8</b>`) → экранирование.

## 7. Удаление того, что используется

- [ ] Архивировать упражнение из двух программ → пропадает из состава; вернуть из архива → встаёт на своё место.
- [ ] Слить два упражнения, оба в одном дне → одна строка, не две.
- [ ] Удалить день, который «следующий по кругу» → подсказка пересчиталась.
- [ ] Вынести/удалить последний день → осиротевшая программа не остаётся строкой «0 дней».
- [ ] Удалить тренировку-источник программы → программа цела (это снимок).

## 8. Команды и состояния

- [x] Пикер упражнений съедает команды (находка 16a).
- [ ] `/start` в каждом состоянии ввода RoutineFlow (имя программы, имя дня, схема) → меню, и следующее сообщение не съедается.
- [ ] Фото/голосовое в состоянии ввода имени или схемы.
- [ ] Кнопка с очень старого экрана после удаления объекта → внятный алерт, не молчание.

## 9. AI-тренер и программы

- [x] Сборка программы по запросу, превью, сохранение, открытие.
- [x] Adherence: «я хорошо иду по программе?» — цифры сошлись.
- [ ] Конфликт имён при сохранении программы от AI → `Заменить` / `Добавить копией` / `Не надо`.
- [ ] Устаревший черновик: собрать две программы, тапнуть кнопку под первой.
- [ ] «Собрать тренировку на сегодня» → старт без сохранения, в Программах ничего не появилось.
- [ ] Правка сохранённой программы словами → превью с блоком изменений, имя не откатывается.

## 10. Шеринг

- [x] Визитка дня: url-кнопка «Забрать себе» + callback «Отозвать ссылку».
- [ ] Визитка программы целиком, урезка до 6 дней с предупреждением.
- [ ] Пустой день не занимает лимит визитки.
- [ ] Приём вторым аккаунтом: новые упражнения в «Другое», повторный приём → `(2)`.
- [ ] Отзыв ссылки → «ссылка устарела», `/start` не ломается.
