# Монетизация: заметки к решению

Статус: **не запущена и не в работе** — записано, чтобы не потерять цифры и
логику. Решение отложено сознательно: на текущем размере аудитории монетизация
даст копейки, а фокус сжигает; сначала рост (см. `GROWTH.md`).

## Правила игры (актуально на август 2026)

Цифровые товары и услуги внутри бота Telegram обязывает продавать только за
**Stars** (XTR) — Bot Payments API с обычными провайдерами (карты, ЮKassa)
оставлен только для физических товаров. Подписка на AI-тренера = Stars, без
вариантов.

### Экономика Stars — честный расчёт

- Пользователь покупает звёзды по ~2–2.5 ₽/шт; через iPhone дороже — Apple
  берёт 30%, через @PremiumBot/Fragment дешевле.
- Разработчику звезда засчитывается по номиналу ~$0.013 при выводе через
  Fragment (TON → фиат); если пользователь купил её через iOS/Android,
  эффективно остаётся ~$0.009.
- Вывод: минимум 1000 звёзд, деньги морозятся на **21 день** (буфер под
  рефанды). По факту за 1000 звёзд на руки выходит 650–850 ₽ — до нас доезжает
  примерно половина того, что заплатил пользователь с айфона.
- **Лайфхак:** звёзды, потраченные на Telegram Ads вместо вывода, идут с
  бонусом **+30%** и без комиссии за вывод. Для нас это основной сценарий:
  выручка сразу реинвестируется в посевы/рекламу, никакого крипто-кешаута.
- Рефандов по звёздам Telegram сам не делает; разработчик может вернуть
  звёзды пользователю без штрафа, если не доставил обещанное.
- Рекуррентные подписки за Stars поддерживаются API нативно
  (`payments.botCancelStarsSubscription` и связанные методы).

### Риск-фон (РФ, август 2026)

- РКН замедляет Telegram с февраля 2026, звонки заблокированы с августа 2025,
  давление нарастает. Полного бана нет.
- Статус Дурова в перечне Росфинмониторинга — персональный, на Telegram как
  организацию не распространяется: покупать Stars/Premium пользователям
  законно (разбор юристов — Meduza, 30.07.2026).
- Триггер для остановки: признание экстремистской организацией **самого
  Telegram**. После этого монетизация через него для РФ-пользователей станет
  юридически опасной.
- Выводы для нас: на Stars бизнес-план не строим; если запускаем — звёзды не
  выводим, а тратим на Telegram Ads (+30%); баланс большим не копим (при
  блокировке сгорит); экспорт и MCP держим рабочими — данные пользователей не
  заперты внутри платформы.

## Механики, когда дойдём

Принцип: платит тот, кому уже ценно, а не тот, кого заперли. Ценность растёт
с каждой записанной тренировкой — монетизируем накопленную историю, но
доступ к ней не отбираем никогда.

1. **Дневник — бесплатный навсегда.** Это виральная поверхность (картинки,
   визитки, рефералка) и источник доверия. Пейволл на свою историю — 
   единственное, за что нас понесут в отзывы.
2. **AI-тренер по подписке** — основной кандидат: он и так стоит денег на
   каждый запрос (xAI, учёт уже есть в `cost_events`). Бесплатно — **10
   вопросов в неделю** (решение 15.08.2026: недельный сброс вместо месячного —
   «до понедельника» ближе, чем «до 1-го числа», и совпадает с тренировочным
   ритмом; PR #386 собирался с месячным лимитом — при пересборке заменить).
   Дальше — **150 звёзд / 30 дней** (~300–375 ₽ юзеру, ~$1.35–1.95 на руки).
3. **Разовые паки** для тех, кто не любит подписки: «15 вопросов тренеру» за
   **50 звёзд** (~100–125 ₽ юзеру, ~$0.45–0.65 на руки; решение 15.08.2026 —
   было 30 вопросов, но это продажа почти по себестоимости).

Правило цены (решение 15.08.2026): **нетто-выручка ≥ ×2 к себестоимости LLM**
при медианном использовании (замеры — `LLM_COSTS.md`, ~$0.015/вопрос при
кэше). Подписка 150 звёзд проходит на медиане 45–65 вопросов/мес; хвост
тяжёлых пользователей накрывают потолки `ai_limits` (особенно потолок живого
поиска — он в 13 раз дороже обычного вопроса). Пак пересчитан под то же
правило: 15 вопросов ≈ 2–2.9×.

4. **Донат «Поддержать проект»** — запускается ДО монетизации и независимо от
   неё: обычный invoice в XTR без выдачи чего-либо взамен, лимиты не трогает,
   стратегии «сначала рост» не противоречит. Пресеты 50 / 150 / 500 звёзд,
   кнопка в главном меню. Заодно это самый дешёвый замер готовности платить.
4. **Премиум-аналитика по истории**: годовой отчёт, разбор всей истории
   AI-тренером, сравнение периодов. Ценность растёт с каждой тренировкой —
   платят именно за то, что навводили.

Порог предложения: не раньше 5–10 закрытых тренировок — раньше человек ещё
не понял ценность, и пейволл его просто выкинет.

Будущая метрика в `/growth`: конверсия в оплату по источникам.

## Готовый черновик кода — PR #386 (не мержить как есть)

Первый заход целиком лежит в открытом PR #386 (`billing.py`, витрина,
три шага платежа, идемпотентность по charge_id, `/refund`, пейволл внутри
`ai_limits.check`, 42 теста). Дизайн-решения оттуда переживут пересборку,
но сам PR разошёлся с main на сотню+ коммитов — перед запуском пересобрать
от свежего main, а не чинить конфликты. При пересборке учесть:

- лимит бесплатных вопросов — недельный (10/нед), не месячный;
- `STARS_PAYMENTS_ENABLED` в PR по умолчанию **true** — перевернуть в false,
  иначе продажа включится в момент выката;
- проверить, что выключенный флаг гасит и сам лимит, а не только витрину, —
  иначе мерж «за флагом» порежет бесплатных без монетизации взамен.

Тест живой оплаты: песочницы у Stars нет — покупка с админского аккаунта за
реальные звёзды, затем `/refund <charge_id>` (звёзды возвращаются, доступ
отзывается, штрафов нет). Сам пейволл админом не проверить — свои аккаунты
лимиты пропускают («Понятно»), нужен чистый аккаунт через `/admin_wipe`.
