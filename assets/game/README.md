# Персонажи «Кач-Раннера» и «Кач-Отряда»

Картинок персонажей здесь больше нет и не нужно. Оба экрана выбора и оба экрана
итога рисуют персонажа сами — тем же векторным атлетом, который бежит по дорожке
(`drawAthlete` / `fighterPortrait` в `game.html` и `game_squad.html`). До этого
поверх вектора подгружались фотореалистичные `power/cross/wrestle/build.jpg`, и в
продукте жили ДВА разных персонажа: «под фото» на карточке выбора и на итоге,
минималистичная фигура — в самой игре. Один персонаж на весь продукт (см.
`TONE_OF_VOICE.md`), поэтому остался вектор.

Если когда-нибудь снова понадобится арт на карточках — рисовать его надо тем же
персонажем и по разделу «Стиль картинок» в `TONE_OF_VOICE.md`, а не генератором
«под фото»: именно расхождение стилей и было причиной отказа.

Остальные файлы в папке — рабочие (модели толпы `.glb`, `three.min.js`,
`gltfloader.js`, `post.js`), их раздаёт роут `/assets/game/{filename}` из
`game_server.py`.
